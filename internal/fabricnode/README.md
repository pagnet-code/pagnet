# Trusted local node composition

`Open` composes the retained genuine registry, compact lexical index and exact
endpoint dispatcher with explicitly supplied authentication, binding/admission,
interception, disclosure validation and observation. It never bootstraps a missing
identity. Installation creates the domain through an explicit owner action.

`Synchronize` processes finite 32-row registry outbox pages and commits index
history before publishing a generation in memory. The caller supplies a finite
page budget and receives whether work remains. Search never drains the registry
or executes an endpoint. An uncertain publication quarantines search; an explicit
reopen validates and restores genuine retained history rather than pretending the
old memory generation still represents the committed watermark.

The current composition searches only its own trust domain, including an omitted
scope. A requested foreign domain produces a structured unsupported result until
an explicit federation binding is configured; it is never silently substituted
with a local search. Semantic/federation composition, transport listeners and
native worker lifecycle are separate integration work, not behavior claimed by
this package.

Actual registry publication, finite partial synchronization, restart equality and
missing-root tests use no cloud account, token, DNS lookup or endpoint effect.
Trusted test authenticator refuses transport requests rather than impersonating
a real peer. Real private-socket authentication and MCP sessions are composed by
the corresponding host boundaries.

Composition receives the actual retained store and restored index in one factory.
Identity providers and binding catalogs share that exact root and sole writer,
rather than opening a second store or reconstructing identity. Owned resources
close on partial construction failure. Current authentication checks the open
retained genesis; historical public verification material alone does not prove
a live root. An optional explicitly configured search reader can compose hybrid
retrieval; no provider or model is installed implicitly.
