# Local original-request authentication

`Authority` is trusted node composition using the actual retained registry `AuthorityIdentity`, exact root owner and namespace audience. Use the same registry instance supplied by the node `PortsFactory`; `store.CurrentAuthorityIdentity(ctx)` supplies the live callback. `CurrentRoot` must return the same current, live retained registry identity and fail on shutdown/corruption/replacement. The package never bootstraps a registry, fabricates a genesis/cloud account, opens another writer or accepts a root from JSON.

`BindOwner` accepts only an actual Unix connection at the configured absolute socket path, beneath an owner-private0700 directory and owner0600 socket. Kernel Owner/ReadProcess establish actual effective-UID/PID/start identity. Linux/macOS non-consuming Poll/MSG_PEEK reject closed connections. An owner-only node explicitly trusts same-UID programs able to use this private socket as the retained registry owner. A node admitting managed native processes must also configure `OwnerValidator`; it classifies actual kernel peer facts against current managed ownership before granting owner identity, on Bind/Build/Authenticate. Omitting environment selectors or requesting owner mode cannot elevate a managed descendant. `SupportsManaged()` lets the host reject a managed resolver without both trusted validators before creating a listener. This process classifier does not replace the runtime sandbox protecting private root files from managed code. Other platforms deny, with no nonce-only fallback.

`BindManaged` additionally requires an owner-provided immutable Activation containing actual local nativeauthority scope, supervisor-captured root PID/start, activation nonce, native generation and native session. `localpeer.VerifyOwned` checks the real current process tree before and after a mandatory `ManagedValidator`. That trusted injected validator must use actual current signed controller/binding/native ownership/origin/session state, not wire selectors or a nonce alone, and return the exact endpoint principal. Its result is rechecked per Bind/Build/Authenticate, never cached across calls. The package's port does not manufacture that native source state; production must wire its genuine owner validator. Existing source Admission A/task lineage remains separate evidence. Fresh MCP originals start origin=actual principal.Ref with no guessed inherited task lineage.

A Session implements `mcpbridge.EnvelopeFactory` plus `Close`. Build takes exactly one typed discover/describe/invoke Call, generates cryptorandom invocation identity/time/principal/root lineage, preserves exact JSON application values (including integers above2^53), target and requested revision. Caller-provided invocation ID is refused. An opaque, nonserializable proof is bound to the exact final generated bytes, factory and live connection; it cannot be used by another factory or cloned. Authentication consumes it once and rechecks current peer/source/root before creating ExecutionContext. Changed principal/request/lineage/audience or expired/canceled/replayed evidence fails closed. Session Close invalidates all pending proofs without closing a transport owned by the MCP server.

Defaults:128 outstanding proofs/session,30-second proof TTL,3-second current-source check deadline. Maximum1024 proofs/session,1-minute TTL,30-second check deadline. Reservation precedes validators/entropy/serialization; failed/consumed/expired proofs reclaim bounded state. Sessions serialize these bounded current checks and own no background per-proof goroutines. Injected current-root/native validators must honor context deadlines; trusted Go composition is not a sandbox against a malicious callback.

Local fixtures cover genuine Unix peers, original factory→actual node authentication, exact bigint/string values, cryptorandom IDs, forged principal/lineage/target/ID/evidence, crossfactory/copied proof, one-use replay, remote closure, private socket permission, changed captured process start, finite quota/expiry/close and changed retained root. A real child process is verified against the actual kernel tree and an actual signed registry binding; the fixture uses an explicit trusted revocation gate, not a claimed production native owner implementation. Production current native validation is composed separately.
