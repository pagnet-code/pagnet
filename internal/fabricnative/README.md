# Local native infrastructure

`Resolver` selects a current, retained `local.native` v1 profile and its genuine
controller/physical binding. Operator registration must install both control rows
before the profile is callable. Missing or partially installed control fails
closed. The injected policy must hold an independent current caller/operator
fence, outside SQLite, through the bounded launch/adoption action.

A controller boot change or descriptor rename acquires current control and
renews the same physical binding. Original launch/capture ownership remains
unchanged. Healthy IPC is reused; refresh only adopts the authenticated original
worker and never starts replacement work. An absent signed launch claim allows
one FULL-claimed spawn. An existing claim with missing or uncertain startup
requires adoption; socket absence never proves no execution occurred.

Provider credential names come from the encrypted signed profile. Values enter
only the inherited memory pipe on initial launch and are not stored in profiles,
descriptors, checkpoints or events. Control HMAC keys remain separate private
infrastructure capabilities; callers receive owned copies and must clear them.

Startup must recover/register every retained worker before exposing the owner
listener. This package provides single-target resolution; root composition owns
bounded profile enumeration and listener ordering. `CloseContext` cancels and
joins resolver actions before registry shutdown; independently owned workers,
real source journals and vendor conversations survive controller closure.

Tests run compiled CLI and fake-runtime processes through real private IPC,
registry restart, original source capture, current descriptor renewal and source
cancellation. Their injected authorization fence is explicit test infrastructure,
not a claim that fixture contexts replace production kernel authentication.
